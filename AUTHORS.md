# Authorship and identity boundary

This public plugin repository was created and defined by:

- Richard Reukema (`richard@phoenixbussolutions.com`)

This is the repository authorship, maintenance, and release-publishing identity. It does not grant or represent ContentTraker access for an installed plugin.

Each installation authenticates independently from inside its host. The required ContentTraker user email is supplied through host configuration and verified against `GET /me` before operations. Consuming-user emails, customer names, workspace names, credentials, and environment-specific authorization are not repository defaults and must not be committed here.
